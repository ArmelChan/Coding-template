# 新手入門：AI 提示詞產生器

這是一個提示詞產生器，幫你把散亂的想法整理成清晰、可重用的 AI 指令。你可以先寫低要 AI 做甚麼、要用哪些資料、想要甚麼格式，再把產生的提示詞複製到 AI 聊天工具試用。

> **「產生提示詞」不等於「執行提示詞」。**
> 這個工具只負責幫你整理要交給 AI 的指令。要取得答案，你要把指令交給 AI 模型，例如貼到聊天工具再送出。單單填好表格，並不會自動得到任何 AI 分析結果。

## 這個工具做甚麼？

很多人一開始只會寫一句：

> 「幫我總結一下銷售。」

AI 只好自己估：是哪幾間店？用哪些數字？要比較甚麼？答案要寫多長？資料不足時，它甚至可能自行編造。

用這個工具，你可以補上 AI 需要的內容：

| 你加入的內容 | 例子 |
|---|---|
| 要用的資料 | 每間店本週和上週的銷量 |
| 規則 | 只可用這些數字；缺少數字就要講明 |
| 答案格式 | 三點摘要 |

這樣 AI 會清楚得多，知道要交付甚麼。提示詞寫得清楚，較有機會得到好答案，但不保證一定正確，答案仍要自己核對。

## 第一次使用：四步完成

先用瀏覽器打開工具網頁（即本專案中的 `index.html` 檔案）。網頁右上角可以切換「繁體中文 | English」，本指引用的是繁體中文介面的名稱。首頁的「快速入門」也有同一個例子，按「幫我填入例子」就能自動填好。

### 1. 選 `Prompting 101`

在「輸入區」頂部按 **`Prompting 101 · 10 段式`**。這個模式把提示詞拆成一格格有標題的欄位，最容易看清一個好提示詞由甚麼組成，適合第一次使用。原有的 **`V2 超級指令`** 模式仍然保留，今次可以先不理。

### 2. 填寫任務、資料和格式

不用填齊十段。跟着下面的例子，只需填寫以下欄位，其餘留空即可：

- **`1 任務背景`**：AI 在幫誰、做甚麼工作
- **`4 詳細要求及規則`**：要遵守的規則，每行一條
- **`7 今次的要求`**：今次要 AI 做甚麼
- **`今次的資料`**：今次要用的資料，在第 7 格下方
- **`9 輸出格式`**：答案要寫成甚麼樣子

### 3. 選 `分析型` 或 `創作型`

在 **`任務性質`** 選擇：

- **`分析型`**：只按你提供的資料分析，缺資料就指出來。
- **`創作型`**：可以提出構思或作推斷，但要列明假設。

銷售例子要的是事實、不是估計，所以選 **`分析型`**。

### 4. 產生、複製，再到 AI 聊天工具試用

按 **`產生提示詞`**。在「產生的提示詞」的 **`提示詞`** 分頁，內容會分成兩段：

- **`SYSTEM PROMPT`**（整體規則）：AI 的角色，以及每次都要遵守的規則
- **`USER MESSAGE`**（今次要做的事）：今次的要求、資料和格式

按 **`複製`** 會連同兩段的標題一併複製。大部分聊天工具只有一個輸入框：照原本次序全部貼上，保留兩行標題，然後送出。

```text
===== SYSTEM PROMPT =====
（整體規則……）

===== USER MESSAGE =====
（今次要做的事……）
```

AI 會把兩段當作同一則訊息來讀。用來試用提示詞沒有問題，但這並不等同程式呼叫 AI 時另外設定的 `system` 指令。如果 **複製** 未能成功，可以自行選取方框內的文字再複製。

## 可直接試用的例子

以下全是虛構數字。把每個方框的內容複製到對應欄位。

**`提示詞名稱`**

```text
每週銷售摘要
```

**`任務性質`**：`分析型`

**`1 任務背景`**

```text
你正協助一位店舖經理，為兩間分店撰寫簡短的每週銷售摘要。
```

**`4 詳細要求及規則`**

```text
只可使用提供的數字。
只作有數據支持的比較。
如缺少某個數字，要清楚註明「未提供」，不可估算升跌。
不要自行推測銷量升跌的原因。
```

**`7 今次的要求`**

```text
請為店 A 和店 B 撰寫本週銷售摘要。
```

**`今次的資料`**

```text
店 A：本週售出 120 件；上週售出 100 件
店 B：本週售出 80 件；上週數字未提供
```

**`9 輸出格式`**

```text
用三點摘要，每點一句。如有變化，要同時列出件數和百分比。
```

**理想輸出**（實際字眼會有出入）：

```text
- 店 A 本週售出 120 件，比上週的 100 件多 20 件（增加 20%）。
- 店 B 本週售出 80 件；由於未有提供上週數字，未能計算按週變化。
- 本週店 A 比店 B 多售出 40 件（120 件對 80 件）。
```

核對兩點：店 A 的增幅是否正好 20 件（20%）；店 B 有沒有被估算升跌，或被加上自行推測的原因。如有問題，就把規則寫得更清楚，再試一次。

## 熟習後可以試甚麼？

- **加入檔案（`附加圖片／檔案`）**：想 AI 參考表格、文件或圖片時，可在第 7 格下方加入支援的檔案（JPG、PNG、GIF、WebP、PDF，或 .txt、.csv 等文字檔）。貼到聊天工具試用時，圖片和 PDF 要在聊天工具另行附上；切勿上載客戶個人資料或機密文件。
- **比較兩個版本（`評測區`）**：想知道兩種摘要指令哪個較好，可捲到頁面下方的 **評測區**（在 Prompting 101 模式下顯示），按 **`把目前表格存成版本`** 存下目前版本，改寫指令後再存一次，然後按 **`新增案例`** 貼上同一份銷售數據。在 **`3 · 執行`** 選 **`手動 · claude.ai（毋須 key）`** 再按 **`建立工作表`**，就可逐格把提示詞複製到 claude.ai，再把答案貼回比較；兩個版本請用同一個模型，才看得出分別是否來自提示詞的改動。
- **接入程式（`API JSON` / `cURL`）**：想把提示詞接入程式或自動化流程時，才需要用 **`API JSON`** 或 **`cURL`** 分頁。複製提示詞到聊天工具試用不需要 Claude API key；只有真正把請求送到 Claude API（例如執行匯出的請求，或在 **`API key`** 方式下按 **`執行評測`**）才需要。

> Claude API 相關功能目前只用模擬回應測試過，未經真實 Claude API 驗證。如要使用，請先用一個小例子試。
