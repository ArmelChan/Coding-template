Prompt generator

Turn rough ideas into clear, reusable instructions for AI.

What is this?

A form that helps you write a prompt: the instructions you give an AI.

How does it help me?

You fill in the task, the information to use and the answer format. The tool arranges them into a clear, reusable prompt, so the AI has less to guess.

Where do I start?

Follow the 3-step quick start below. It comes with a made-up sales example you can fill in with one click.

This tool writes the prompt; it doesn't give you the answer. To get an answer, copy the prompt into an AI chat tool (such as claude.ai) and send it there.

Start the quick start

Quick start: your first prompt in 3 steps

We'll use a made-up example. Store A sold 120 units this week and 100 last week. Store B sold 80 units this week; last week's figure is not available.

  1. Choose Prompting 101

    It splits a prompt into labelled boxes, so it's the easiest place to start. V2 Super Instruction is a more advanced mode you can skip for now.

  2. Fill in the task and the data

    For this example you only need five boxes: Task Context, Detailed Task Description & Rules, Immediate Task / Request, Input Data and Output Formatting. Keep Task Nature on Analytical: we want facts, not guesses.

    Fills the Prompting 101 boxes with the example, in the language you're viewing. You can edit everything afterwards.
    See what gets filled in

  3. Generate and copy the prompt

    Click Generate Prompt, then Copy. The result has two parts: SYSTEM PROMPT (the overall rules) and USER MESSAGE (what to do this time). Paste both, in order and with their headings, into an AI chat tool and send. Only then do you get an answer.

    What a good answer looks like 
    - Store A sold 120 units this week, up 20 units (20%) from 100 last week.
- Store B sold 80 units this week; last week's figure was not provided, so no weekly change can be given.
- This week, Store A sold 40 more units than Store B (120 vs 80).

    The exact wording will vary. Check that Store A is up 20 units (20%) and that Store B has no guessed change.

Later, you can compare prompt versions in Evaluation Lab or export to the Claude API. You don't need either to get started.

    Evaluation Lab

    Compare prompt versions on the same test cases and see which one gives the answers you expect. This is optional: you don't need it to write your first prompt.

    1 · Prompt versions

    Saved in this browser only. Ticked versions are included in the run. Each version can use its own model and effort; to compare models on one prompt, duplicate the version and change its model.

    2 · Test cases

    Each case replaces the Input Data. Expected result: text that must appear (case and spacing ignored), or a /regex/flags. Leave blank to judge by eye.

    3 · Run

    API: the files are sent with each request. Manual: each cell names the files, and you attach them in claude.ai yourself.
    1. Click Build worksheet.
    2. In each cell, click Copy prompt, paste it into a new claude.ai chat and send it. One chat per cell keeps earlier answers from leaking in.
    3. Paste Claude's full reply back into the cell. It is graded right away and saved in this browser.
    If a version sets a model, pick that model in claude.ai. Effort and the API settings don't apply here.
    Kept in memory only, never saved. Sent directly from this browser to api.anthropic.com. Use a key with a spend limit, and never on a shared computer. A version left on "default" uses the model and effort from API Export Settings. max_tokens, caching and fallback always come from there.
